IMÁGENES DE PLATAFORMAS (opcional)

Si quieres usar el logo o la imagen oficial de cada plataforma, súbela tú:
  - Desde el panel: Admin > Productos > "Subir imágenes de varias plataformas".
    Nombra cada archivo como la plataforma (netflix.png, disney.png, max.webp...) y súbelos todos juntos.
  - O pon aquí los archivos con el id del producto y haz deploy:
      netflix  max  disney  prime  paramount  universal  vix  crunchy  plex
      spotify  winsports  gemini  capcut  canva  combo1  combo2  combo3  combo4
    Formatos: .png .jpg .webp (horizontal 800x500 o cuadrado). 

Si un producto no tiene imagen, la tienda genera arte propio con sus colores.
Logos de redes y fondo de temática: se suben en Admin > Tienda y Admin > Temas.
